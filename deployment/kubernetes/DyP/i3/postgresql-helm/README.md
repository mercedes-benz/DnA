# I³ PostgreSQL

I³ PostgreSQL provides high availability and easy replication mainly for DHC CaaS. In addition, it handles backup/restore and includes security hardening.

## Introduction

This chart bootstraps an I³ PostgreSQL database on a [Kubernetes](http://kubernetes.io) cluster using the [Helm](https://helm.sh) package manager.

## Installation

## Prerequisite: Helm client
The I³ PostgreSQL images can be deployed via [Helm chart](../../src/chart). You need the Helm client to be able to deploy Helm charts. We recommend using Helm 3 but our Helm chart is still downwards compatible with Helm 2.

### Deployment

To create YAML files from the chart with the release name `my-postgres` and apply the YAMLs with `kubectl`:

```bash
# Download Helm Chart
helm repo add i3 https://registry-emea.app.corpintra.net/chartrepo/i3 # you need to do this only once
helm repo update
helm pull i3/postgresql-helm --devel
tar xvf postgresql-helm-*.tgz

# Copy values.yaml where you can edit them
cp postgresql-helm/values.yaml ./my-values.yaml

# In the helm chart the registry value points as per default to EMEA Harbor. Locations in Asia or America need to change the registry entry to their own region.

# Create separate namespace for database
kubectl create namespace database

# Apply the Helm Chart
helm install --namespace database \
my-postgres postgresql-helm \
-f my-values.yaml  
```

The [configuration](#Configuration) section below lists all possible parameters that can be configured during installation.

## Uninstall

To uninstall/delete the `my-postgres` release:

```bash
helm uninstall --namespace database my-postgres
```

This command removes all the Kubernetes components associated with the chart (except the PVCs) and deletes the release.
